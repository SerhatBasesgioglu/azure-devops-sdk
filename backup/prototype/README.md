# Handwritten prototype snapshot

This directory preserves the handwritten prototype before migration to the
spec-generated package layout. It is a historical, non-installed snapshot, not
a runnable SDK. In particular, `runtime.py` is retained only as part of this
snapshot; active source uses `src/azure_devops_sdk/_transport.py`. The old
project/repository facade and demo entry points are preserved only for history.

No credentials or environment files are included.
